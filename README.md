# Portfolio personnel de Mouhamed Fall

Portfolio statique, responsive et accessible dédié à la présentation de mon parcours en systèmes embarqués, microélectronique et intelligence artificielle embarquée.

## Structure

- index.html : page d'accueil
- about.html : parcours académique et compétences
- projects.html : projets techniques
- contact.html : coordonnées et contact
- styles.css : design global et responsive
- script.js : interactions et thème
- assets/ : images, icônes et documents

## Technologies

- HTML5
- CSS3
- JavaScript Vanilla

## Déploiement

Le site est prêt pour GitHub Pages.
